# Інструкція з розгортання дипломного проєкту

**Тема:** Інформаційна система для соціальних мереж з текстовою аналітикою (ETL + NLP).
**Стек:** Node.js (Express) + Python (FastAPI / Flask) + Redis + ванільний фронтенд. Усе пакується у Docker.

---

## 1. Запуск проєкту — три команди

```bash
cd /шлях/до/папки/ДИПЛОМ
cp .env.example .env
docker compose up -d --build
```

Перша команда `docker compose up --build` виконує одразу все:

1. Збирає образ **backend** (Node.js + статика фронтенду).
2. Збирає образ **nlp-service** (Python 3.11 + PyTorch CPU + transformers + sentence-transformers + Telethon).
3. Стягує офіційний образ **Redis 7**.
4. Створює мережу і чотири томи (для кешу моделей Hugging Face, файлу Telegram-сесії, даних Redis і ETL-lineage).
5. Запускає чотири контейнери у фоні (`-d`).

**Перший запуск триває ~3–5 хвилин** через завантаження ~1 ГБ Python-залежностей. Наступні запуски — секунди.

Після старту відкрийте у браузері:

**http://localhost:3000**

## 2. Які джерела даних реально працюють і чому

Система спроєктована як «розширюваний шлюз»: модуль збору поверх **Reddit API**, **Telegram (Telethon, MTProto)**, **RSS-стрічок** і **X (Twitter API v2)**. Реальна доступність кожного джерела залежить від політик платформ, які не залежать від нашого коду. Поточний стан в дипломному прикладі:

### Telegram — працює (основне джерело)

- Збір реалізовано через офіційну бібліотеку **Telethon** (MTProto-протокол), із попередньою інтерактивною авторизацією через `python telegram_login.py`. Файл сесії зберігається у томі `tg-session` і автоматично використовується при кожному запуску.
- У `.env` задано `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` (отримано з [my.telegram.org/apps](https://my.telegram.org/apps)) і список з 11 публічних україномовних каналів у `TELEGRAM_CHANNELS` (новини, OSINT, регіональні видання, офіційний канал Президента).
- Telethon робить підрядковий пошук ключового слова у нещодавніх повідомленнях каналів, додає реакції-емодзі у текст (це використовується для аналізу емоційних сигналів — позитив/негатив/нейтрал за реакціями).

### RSS — працює частково (резервне «новинне» джерело)

- Підтримується **довільний список RSS-стрічок** через змінну `RSS_FEEDS` у `.env` (значення задано — 15+ стрічок українських та міжнародних медіа).
- На практиці частина стрічок недоступна або повертає невалідний XML, бо видання час від часу змінюють формат, URL або блокують неінтерактивний User-Agent. У моєму середовищі стабільно працюють:
  - `tsn.ua`,
  - `suspilne.media`,
  - `bbc.com/ukrainian`,
  - `pravda.com.ua`,
  - `unian.net`,
  - `nv.ua`,
  - `obozrevatel.com`,
  - `gordonua.com`,
  - `interfax.ru`,
  - `telegraf.com.ua`.
- Помилки на кшталт `lb.ua: Attribute without value`, `dt.ua / zn.ua: Feed not recognized as RSS`, `ukrinform: 404`, `eurointegration: Non-whitespace before first tag` означають, що **сама стрічка зараз віддає не-RSS контент** (HTML-сторінку cookie-баннера, помилку 404 тощо). Це **зовнішнє обмеження**, а не помилка дипломної ІС: код коректно ловить виняток і йде далі по списку. Достатньо вписати інший URL або зачекати, поки видання поверне коректний формат.

### X (Twitter) — недоступне без платного тарифу

- Інтеграція реалізована і протестована проти ендпоінта `GET /2/tweets/search/recent` із заголовком `Authorization: Bearer ...`.
- При живому запиті API повертає `402 Payment Required: ... does not have any credits to fulfill this request`. Тобто акаунт розробника зареєстрований, але **безкоштовний тариф (Free) не дає доступу до Recent Search** — для цього потрібен тариф Basic ($200/міс) або вище. Це **політика X/Twitter з 2023 року**, а не помилка реалізації.
- Якщо викладач захоче побачити, як виглядає шлях X у системі, можна тимчасово увімкнути режим демо (`ALLOW_MOCK=1` у `.env`) — він підставить синтетичні твіти, щоб продемонструвати, як проходить решта пайплайну.

### Reddit — вимкнено (потребує реєстрації застосунку)

- У дипломному `.env` ключі `REDDIT_CLIENT_ID`/`REDDIT_CLIENT_SECRET` не заповнені, тому в `GET /api/health` поле `reddit: false`. Щоб увімкнути: створити застосунок на https://www.reddit.com/prefs/apps (тип `script`), отримати пару `client_id`/`client_secret`, вписати у `.env` і перезапустити `docker compose`.
- Reddit з 2023 року також обмежив безкоштовний доступ до API; для академічного використання достатньо стандартного OAuth-токена, але треба окремо подавати заявку, якщо обсяг великий.

### Facebook / Instagram — не реалізовано як реальне джерело

- Meta з 2018 року після інциденту Cambridge Analytica закрила публічний доступ до контенту звичайних користувачів і сторінок. Поточний Graph API дозволяє лише пости **власних** сторінок із токеном власника, чого недостатньо для широкої аналітики. У роботі це джерело залишене як заглушка, що може віддавати демо-дані, якщо увімкнено `ALLOW_MOCK=1`.

### Висновок про джерела

Те, що зараз працюють лише **Telegram** і **RSS**, — це **наслідок зовнішньої політики платформ**, а не обмеження дипломної ІС. Архітектура спроєктована так, що додавання будь-якого нового джерела зводиться до створення одного модуля у `backend/src/collector/` і дописування одного рядка у `parseSources()` — решта пайплайну (дедуплікація, мовний фільтр, NLP, візуалізація) уже готова. Telegram і RSS у комбінації покривають основну задачу диплому — аналіз публічного україномовного інформаційного простору в режимі, близькому до реального часу.

## 3. Як користуватись інтерфейсом

1. Відкрити http://localhost:3000
2. У полі **«Ключове слово / тема»** ввести запит (наприклад: `Україна`, `Київ`, `вибори`, `Tesla`).
3. У блоці **«Джерела»** залишити галочки **Telegram** і **RSS** (X можна зняти, бо немає кредитів).
4. Обрати мову (`Усі` / `Українська` / `English`) і ліміт постів.
5. Натиснути **Analyze**.

Через 5–20 секунд (залежно від розміру вибірки) у нижній частині сторінки з'являться:

- ETL-пайплайн (extract → clean_dedupe → nlp) з лічильниками і breakdown по джерелах.
- Графік тональності (позитив / нейтрал / негатив, %).
- Графік активності за днями.
- Топ-слова (частоти) + хмара слів.
- Ключові фрази **KeyBERT** і резерв **TF-IDF**.
- Тематичне моделювання **LDA**.
- Емоційні сигнали з реакцій Telegram-постів.
- Таблиця фрагментів постів із джерелом, мовою та класифікованою тональністю.
